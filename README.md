# Appointments React (scaffold)

This project is a small React port of the existing `FirstPage.html` and `AppointmentDetailPage.html`.

To run:

```bash
cd "d:\Naresh-Learning"
npm install
npm run dev
```

Open the printed local URL in your browser. The app uses `localStorage` to persist appointments.

Notes:
- Routing is implemented using the URL hash: `#/` (list) and `#/detail?id=<id>` (details).
- If you want React Router, I can add it.
